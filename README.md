## Featured Projects

### 🚦 Traffic Sign Detection & Recognition

An object detection project built using YOLOv8 to identify and classify traffic and road signs across 29 classes.

* **Technologies:** Python, YOLOv8, Computer Vision
* **Focus:** Object detection, model training, and performance evaluation.
* **Repository:** [Traffic Sign Detection](https://github.com/maram-elaian/Traffic-Sign-Detection-and-Recognition-using-YOLOv8)

### 🎨 ChromaSight AI

An assistive computer vision project designed to improve visual accessibility for people with color vision deficiency through color simulation, confusion-region detection, and texture-based visual cues.

* **Technologies:** Python, OpenCV, Gradio, Image Processing
* **Focus:** Accessibility, real-time image processing, and visual enhancement.
* **Repository:** [ChromaSight AI](https://github.com/maram-elaian/ChromaSight-AI)

### 💬 Arabic Emotion Detector

An Arabic text classification application that identifies emotional and linguistic patterns in text using traditional machine learning techniques.

* **Technologies:** Python, Scikit-learn, TF-IDF, Logistic Regression, Streamlit
* **Focus:** Arabic NLP, text classification, and interactive machine learning applications.

### 🎨 BRANDORA

An AI-powered brand identity generation and evaluation project exploring how language models and image-generation tools can help transform creative briefs into visual branding concepts.

* **Technologies:** Python, LLM APIs, Generative AI
* **Focus:** Model experimentation, structured outputs, and AI-generated brand concepts.
